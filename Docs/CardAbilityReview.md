# Card ability review

Reviewed all 63 Objects, 166 Characters and 142 Armies using their current names, descriptions and quotes. Existing abilities are preserved; additions do not change procChance or balance stats. Metaphorical fire/cold and ordinary armor/healing do not alone grant combat keywords. Character-only abilities are assigned only to Characters. Modular decks reference these canonical cards by ID.

## Sprite audit

All mapped ability sprite names exist in `Assets/Art/Fonts/Spritesheets/common_spritesheet.asset`; no missing-sprite references need adding.

Character-only abilities currently reuse icons: Scholar/book, Lieutenant/strengthened, Shieldbearer/fortified, Ranger/bow, Wormtongue/speech, Friendly/loyalty, Cruel/dagger, Warlock/spell, Leader/banner, EasternerLeader/scimitar, SouthernerLeader/sword, OrcWarChief/axe, WarTroll/mace. ## Validation

`unity command eval_file Tests/CardAbilityChecks.cs` checks all 371 cards, every assigned ability in its full rendered description, enum validity, character-only restrictions, quote preservation and actual TMP sprite lookup. Existing unrelated card data and assignments were retained. No combat balancing or gameplay implementation was changed.
