# Twilight Realm presentation

The default board now uses a painted landscape beneath translucent midnight green surfaces, thin aged gold inlays and sage player accents. Short lane headings replace the long dashboard labels. The hand shows illustrated card faces with names, costs, combat values and parchment type ribbons; hovering retains the complete rules face. Champions use the space formerly occupied by their mostly empty description panels for larger portraits. Rules and match collections are unchanged.

`BoardSkin.backdrop` owns the illustration; clearing it reveals the existing animated scene again. An aspect fitter crops the backdrop to fill different viewport shapes without stretching it. Decorative graphics do not intercept pointer input. `AgentScripts/ApplyIllustratedBoard.cs` reproduces the default asset settings through Unity CLI in Edit mode.

Artwork: `Assets/Art/Board/TwilightRealm.png`, created with the built-in image generation tool. Prompt:

> Create a production background illustration for a dark fantasy strategy card game, landscape 16:9, highest resolution. A richly painted old-world fantasy oil illustration: sweeping misty river valley at dusk, distant jagged mountains, ancient gothic castle on the upper right hillside, dark pine woodland on the left, small warm torchlit ruined stone arches framing the lower corners, muted twilight silver sky above. Deep forest green and blue-black shadows, aged golden highlights, luminous soft mist. Intricate traditional collectible fantasy card illustration, tangible brushwork, atmospheric and solemn, no photorealistic 3d rendering. Composition: the central 70 percent is a broad quiet valley with subtle detail so foreground playing cards remain legible, castle in upper right quarter, darker foreground at bottom. Full bleed artwork only, absolutely no text, no letters, no cards, no UI, no borders or panels. Save this as a usable project background asset.

Validation through the live Unity Editor: 8 illustrated-face/inspection checks, 148 engraved-board assertions (including input transparency, health and layout), 15 inspection checks, and 42 responsive zone sizes passed. Existing test harnesses were updated for TMP health text, health bars living inside champion cards, empty piles and animated card poses. Layout checks measure unrotated slots; they do not assert that intentional rocking and action glow remain inside those slots.
